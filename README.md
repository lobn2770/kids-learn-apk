# 宝贝学习乐园 · 7 岁版

一位爸爸给自己孩子写的纯离线学习网页应用，已打包成安卓 App 自用。

## 特点

- **完全离线**：不申请网络权限，无登录、无同步、无广告
- **英语岛**：字母卡片、配对游戏、自然拼读 32 卡、听音选图 48 词（内置真人音色发音）
- **古诗花园**：100 首小学必背古诗，逐字拼音标注、简介与白话译文、每首配朗读音频
- **数学城**：口算竖式、乘法口诀、除法口诀、数独训练，四个题型**各 10 关**（每关答对 3 题升级），难度依次递进至三年级水平；满 10 关后对应按钮变金色并标「已通关」
- **逻辑挑战**：找规律、图形配对、排序题，同样**各 10 关、每关 3 题**，关卡越高题型越难
- **闯关冒险**：**10 关、每关 5 题**（答对 3 题过关），同一关内题目不重复，难度随关卡提升；通关全部 10 关有额外提示
- **知识图谱**（独立页面，v2.6 重构）：1-6 年级数学 / 语文 / 英语 / 科学共 120 个知识点，以 **ECharts 关系图**呈现——节点按「前置链拓扑分层」布局（基础在下、进阶在上），虚线箭头表示前置关系；支持科目筛选（再点当前科目切回**四科同屏四象限**）、年级筛选（1-6 / 全部）、按名称或**别名搜索**（命中红框高亮、其余淡化）；三态学习标记（未开始 / 学习中 / 已掌握），侧边栏实时显示进度卡片与掌握度进度条，详情面板含说明、重要性、别名、例题、教材位置、前置/后续知识跳转；图表库 echarts.min.js 已本地化，完全离线可用

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 页面主体（HTML + CSS + 全部逻辑） |
| `knowledge-graph.js` | 知识图谱数据（120 个知识点，含前置关系、**知识板块**、**上册/下册**、重要性、别名、例题、教材位置） |
| `echarts.min.js` | ECharts 5.5.0 本地图表库（v2.6 新增，Apache-2.0，离线渲染知识图谱关系图） |
| `poems100.js` | 100 首古诗数据（标题/作者/诗句/简介/译文） |
| `poems100_pinyin.js` | 逐字拼音数据（与诗库逐字符对齐） |
| `audio/` | 206 个预生成朗读音频（百度大模型音色） |

## 本地运行

直接用浏览器打开 `index.html` 即可（需通过 localhost 或直接双击打开，音频为相对路径引用）。

## 打包安卓 APK

基于 Capacitor 打包，步骤见 `APK打包说明.md`。
